E-commerce — Plataforma de Vendas Online

Projeto de e-commerce desenvolvido do zero, com o objetivo de aplicar na prática conceitos de desenvolvimento web, arquitetura de aplicações, autenticação, persistência de dados e implantação em ambiente de produção.

A aplicação possui uma experiência completa de compra para usuários e um painel administrativo para gerenciamento da operação da loja.

Principais funcionalidades

👤 Área do cliente

  • Cadastro e autenticação de usuários
  • Catálogo de produtos
  • Busca por produtos
  • Filtros por categoria
  • Página de detalhes dos produtos
  • Sistema de favoritos
  • Carrinho de compras
  • Cadastro e gerenciamento de endereços
  • Finalização de pedidos
  • Integração com pagamento por link externo
  • Envio de e-mails automáticos

🔧 Área administrativa

  • Cadastro e gerenciamento de produtos
  • Upload e gerenciamento de imagens
  • Controle de estoque
  • Criação e gerenciamento de categorias
  • Configuração de formas de pagamento e envio
  • Gerenciamento de pedidos
  • Gerenciamento de clientes
  • Cadastro de redes sociais da loja

⚙️ Tecnologias

  • Backend: Java, Spring Boot, Spring Data JPA e PostgreSQL
  • Segurança: Spring Security e Keycloak
  • Frontend: Angular, Angular Material e CSS
  • Infraestrutura: Docker, VPS Hostinger e Certbot/SSL
  • Arquitetura: API REST integrada a uma aplicação frontend Angular

🚀 Deploy

O projeto foi implantado em ambiente de produção, utilizando Docker e certificado SSL, permitindo que a aplicação seja acessada publicamente.

SigVa — Plataforma de Gestão de Varejo

O SigVa é uma plataforma web de gestão de varejo desenvolvida com o objetivo de ajudar pequenos empreendedores a organizar e administrar seus negócios de forma simples, centralizada e eficiente.

O sistema reúne recursos para gerenciamento de produtos, estoque, funcionários, pedidos e vendas, além de disponibilizar indicadores e relatórios que auxiliam na análise do desempenho do negócio.

Principais funcionalidades

📦 Gestão do negócio

  • Cadastro e gerenciamento de produtos
  • Controle de estoque
  • Gestão de funcionários
  • Gestão de pedidos
  • Gestão de vendas
  • Configuração de meios de pagamento

📊 Análise e relatórios

  • Análise de faturamento
  • Dashboard com indicadores do negócio
  • Relatórios de produtos
  • Relatórios de estoque
  • Relatórios de pedidos
  • Relatórios de vendas
  • Relatórios de faturamento

⚙️ Tecnologias

  • Backend: Java 21, Spring Boot 3, Spring Data JPA e PostgreSQL 17
  • Segurança: Keycloak 26
  • Frontend: Angular 19, Keycloak Angular, Angular Material e Ngx Charts
  • Infraestrutura: Docker, Nginx e VPS Hostinger
  • Segurança da aplicação: HTTPS com certificado SSL da Let's Encrypt
  • Arquitetura: API REST integrada a uma aplicação frontend Angular

🚀 Deploy

O SigVa foi implantado em ambiente de produção utilizando uma VPS da Hostinger, Docker e Nginx. A aplicação possui domínio próprio e comunicação segura através de HTTPS com certificado SSL da Let's Encrypt.

SECRED — Sistema de Credenciamento de Membros

O SECRED é um sistema web desenvolvido com o objetivo de simplificar e modernizar o processo de credenciamento de membros para Igrejas Evangélicas, proporcionando uma plataforma centralizada para organização e gerenciamento das informações.

Esse projeto foi especialmente escolhido para o meu trabalho de conclusão de curso (TCC) na minha graduação.

Principais funcionalidades

👤 Gestão de membros

  • Cadastro e gerenciamento de membros
  • Cadastro e gerenciamento de congregações
  • Cadastro e gerenciamento de cargos
  • Emissão de relat-orios
  • Emissão de credenciais

⚙️ Tecnologias

  • Backend: Java, Spring Boot, Spring Data JPA, Spring Security, PostgreSQL, Thymeleaf, Cloudinary e Maven
  • Segurança: Spring Security e Keycloak
  • Frontend: Angular 16, Angular Material, TypeScript, HTML e CSS
  • Ambiente: Node.js e NPM
  • Banco de dados: PostgreSQL
  • Armazenamento de imagens: Cloudinary
